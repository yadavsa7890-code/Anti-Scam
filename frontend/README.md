# AntiScam

AntiScam is a web-based application designed to help users recognize online scams, test their scam awareness, and receive basic safety guidance.

## Features

- Scam Simulator
- Scam Awareness Quiz
- Score Tracking
- Guided Scam Help Assistant
- AI-powered AntiScam Assistant
- Official Cyber Crime Reporting guidance
- Responsive user interface

## Technologies Used

- React
- Vite
- React Router
- HTML
- CSS
- JavaScript

## Running the Frontend

Install the required packages:

npm install

Start the development server:

npm run dev

The frontend will run using the Vite development server.

## Backend

The AI Assistant requires the AntiScam backend server to be running.

See the backend setup instructions for information about configuring and starting the server.
